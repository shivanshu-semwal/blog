This blog post is to help you use modern web in a productive manner.

## Web Browser

Choose an open-source browser with good privacy defaults. Firefox is a good option, along with Librewolf and Chromium.

## Browser Extensions

Useful open-source extensions include:

- `stylus`
- `vimium`
- `uBlock`
- `Privacy Badger`
- `Dark Reader`
- `search by image`
- `reader view`
- `libredirect`

## Password manager

Use a password manager, preferably one with good security and cross-browser syncing.

## Bookmark manager

A bookmark manager is extremely helpful when you have too many bookmarks.

## Search engine

Use a privacy-focused search engine or rotate between engines if needed.

## Start page

Use a custom start page or a browser extension that shows your bookmarks.
