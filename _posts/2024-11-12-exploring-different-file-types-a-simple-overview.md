A computer file is a resource for recording data on a computer storage device, primarily identified by its filename.

## Types

Files can be categorized by purpose and content:

- Text files
- Image files
- Audio files
- Video files
- Documents
- Application files
- Archives

## Properties of files

Every file has:

- a filename
- an extension
- a file size
- compression status
- encryption status

## Audio files

Audio files store sound digitally.

Common audio formats include:

- `.mp3`
- `aac`
- `ogg`/`vorbis`
- `flac`/`alac`
- `wav`/`aiff`
- `m4a`

## Video files

Video files store both audio and images, and the extension usually reflects the container format.

Common video containers:

- `mp4`
- `mkv`
- `webm`
- `avi`

Common video codecs:

- `h.264`
- `h.265`
- `vp8`
- `vp9`

## Image files

There are two main approaches:

- Vector images
- Raster images

Common image formats:

- `jpeg`
- `gif`
- `png`
- `tiff`
- `svg`
- `webp`
